# 🏋️ Nisha's Fitness Studio

A modern, responsive fitness studio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

Designed to provide a premium digital experience for visitors while showcasing gym facilities, trainers, membership packages, and contact information in a clean and engaging way.

---

## ✨ Features

### 🎯 Modern Hero Section

* Full-screen hero layout
* Responsive design
* Custom branding
* Smooth animations

### 🏋️ About Section

* Trainer showcase
* Gym introduction
* Responsive image cards
* Mobile-optimized layouts

### 📸 Gallery

* Interactive image gallery
* Hover animations
* Premium card design
* Responsive grid system

### 💰 Membership Packages

* Pricing cards
* Mobile-friendly layout
* Call-to-action buttons

### 📍 Contact & Location

* Click-to-call support
* Google Maps integration
* Instagram integration
* WhatsApp integration

### 📝 Lead Collection Modal

Visitors can submit:

* Name
* Phone Number
* Age
* Fitness Goal
* Preferred Workout Time
* Additional Message (Optional)

The information is automatically formatted and sent through:

* WhatsApp
* Email

### 🚪 Intro Screen

Custom animated intro experience featuring:

* Gym branding
* Logo reveal
* Animated opening panels
* Session-based display

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
